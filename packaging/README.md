# تثبيت منظومة الخدمات والصيانة

شغّل `output/MaintenanceSetup/Setup.exe` على Windows ‏x64. يحتوي المثبّت على تطبيق المنظومة ومكونات .NET Desktop وDevExpress وSQL Client وقوالب الطباعة. يتصل التثبيت بخادم SQL المحدد، ويمكن تشغيله من دون إنترنت. ينشئ اختصارًا على سطح المكتب وفي قائمة ابدأ باسم **منظومة الخدمات والصيانة** ويضع الملف التنفيذي `منظومة الخدمات والصيانة.exe` في `%LOCALAPPDATA%\SSF\MaintenanceServices\Application`.

1. أدخل اسم مثيل SQL Server واسم مستخدم SQL وكلمة مروره مباشرة. اتصال SQL مشفّر ويقبل شهادة الخادم مباشرة.
2. جهّز `Maintenance_Dabase` بمخطط المنظومة الحديثة. يستخدم التطبيق حساب الاتصال الذي يحفظه المثبّت مشفّرًا لحساب Windows الحالي.
3. اضغط **تثبيت المنظومة**. يختبر الوضع الافتراضي الاتصال والمخطط بقراءة فقط ثم يحدّث الملفات والاختصارات. يمكن تكراره على قاعدة قيد الاستخدام حتى إن لم يكن فيها سجل ترحيل.
4. لنقل البيانات القديمة لأول مرة، فعّل **ترحيل بيانات Cont_maint لأول مرة**. يلزم أن تكون الجداول المعنية في الوجهة فارغة، وأن يكون المصدر على المثيل نفسه، وأن يملك الحساب صلاحية قراءة المصدر وكتابة الوجهة وإنشاء جداول سجل الترحيل. إذا اكتمل النقل سابقًا، يتجاوز المثبّت الترحيل استنادًا إلى سجله.

ينقل الترحيل 23 جدولًا مشتركًا داخل معاملة واحدة ويتحقق من أعداد الصفوف. يسجّل `SetupLegacyMigration` اكتمال الترحيل ويمنع تكراره. يختار نوع الخدمة من أول بند بحسب `ID` ومفتاح التكليف الكامل، ويسجل بنود التكليفات متعددة الأنواع وأنواع البنود اليتيمة في `SetupLegacyServiceTypes`. تُحفظ تفاصيل الصيانة والقطع بلا تكليف في جدولي الأرشيف الموجودين في الوجهة. يسجل `SetupLegacyMissingEmployees` معرّفات الموظفين غير الموجودين، ويترك حقولهم الاختيارية فارغة في التكليفات. ترتبط حركات التدقيق بالحسابات الحالية أو بحسابات أرشيفية معطّلة تحمل الأسماء القديمة.

لإعادة بناء الحزمة من المشروع شغّل `packaging/Build-OfflineSetup.ps1`. يحتاج البناء إلى SDK وحزم NuGet المرخّصة وقوالب التقارير القديمة المشار إليها في مشروع المنظومة.

في 2026-11-16 أُعيد بناء المثبّت بإصدار التطبيق الحالي. التحديث الافتراضي يتحقق من الاتصال ومخطط الوجهة باستعلام قراءة، ثم يستبدل الملفات ويعيد إنشاء الاختصارات. خيار ترحيل Cont_maint اختياري وغير محدد عند كل فتح للنافذة، ويستخدم معاملة SQL والقفل وسجل SetupLegacyMigration كما في النسخة السابقة. أُدرجت في الحزمة قوالب التكليف والمواد والإنهاء المحسّنة وقالبا الفحص اليومي الأصليان بصيغة REPX. فُحصت نافذتان للمثبّت، وفُك فهرس Setup.exe للتحقق من تطابق تجميعة Release ونص SQL المضمّن وبصمات ستة قوالب. لم يتوفر SQL LocalDB للاختبار بسبب تعذر الوصول إلى إعداداته في سجل Windows. لم تُفتح قاعدة العمل. تعذرت مزامنة NotebookLM لعطل مشغله المحلي.
